# 多语言 (i18n) 指南

站点界面与讲义支持多种语言。当前内置 `zh-CN`（默认根语言，网址 `/`）与 `en`（网址 `/en/`）。本文讲怎么用。

## 1. 开启 / 关闭语言

`site/lecture.config.ts` 的 `i18n` 块，默认值如下，不写就是默认：

```ts
export default defineLectureConfig({
  i18n: { root: 'zh-CN', locales: ['zh-CN', 'en'] },
})
```

- `root` 是 `/` 的语言；`locales` 必须包含 `root`；可选值 `zh-CN`、`en`。
- 只留根语言（`locales: ['zh-CN']`）= 单语言站：构建时 `docs/en/**` 被排除，产物里没有 `/en/` 页面，语言切换器与提示条都不渲染。
- 改完重新 `npm run build`。

## 2. 译文放哪

只要放一个真实文件，该讲就算「已译」：

```
content/lectures/<语言键>/<课程组目录>/Lxx.md   内容模式，例：content/lectures/en/g01/L03.md（content:sync 复制到 site/docs/en/g01/L03.md）
site/docs/<语言键>/<课程组目录>/Lxx.md          原位模式，例：site/docs/en/g01/L03.md
```

- 内容模式下语言目录里只放组目录：直接放在 `lectures/en/` 下的文件、`index.md`、`dashboard.md`、`[group]` 会被 `content:sync` 拒绝（英文首页与组页是引擎页面）。`npm run new:lecture -- --title-en ...` 同时写译本骨架；`check:content` 核对原文存在、`title`、图表占位一致。

- 语言键：`en` 对应 `en`，`zh-CN` 作为非根语言时对应 `zh`。
- 文件名、目录与中文原文一一对应；frontmatter 的 `title` 必须写（侧栏与组页用它）。
- 图表占位 `<figure class="chart" data-lecture=... data-id=... data-type=...>` 与图表 sidecar JSON 保持和原文一致，译文不另配图表文件。
- 英文首页 `docs/en/index.md` 与英文组页（动态路由 `docs/en/[group]/`）已有，不用手写；组页数据来自 `groups` 的 `i18n` 字段。
- 译文里写 `./L02` 这类相对链接即可：本语言没有那一讲时，构建会把链接改写到中文原文。

## 3. 没有译本的讲义怎么处理

- 英文侧栏只列已译的讲。
- 英文组页列出本组全部讲：已译的指向 `/en/<目录>/Lxx` 并显示译名；未译的指向中文原文 `/<目录>/Lxx`，显示原标题，并带一个「中文」小标。组页顶部写「Translated N / M lectures」。
- 阅读进度、批量标记、沉浸阅读都用去掉语言前缀的路径作键，同一讲中英文版共享进度。
- 不做按浏览器语言的自动跳转。

## 4. 字典规则

文件：`site/docs/.vitepress/i18n/zh-CN.ts`（键的真源）与 `en.ts`。

- 键：小写点分、扁平，例 `home.hero.start`、`group.translated`。
- 占位符 `{name}`；两份字典同一个键必须用同一组占位符。
- 新增界面文字必须**同时**写进两份字典；`en.ts` 缺键或多键会让 `vue-tsc` 失败，单元测试再校验键集合与占位符。
- `theme/` 下不许出现硬编码中文：`npm run check:i18n` 对照 `tests/i18n-hardcode-baseline.json`，只许减少不许增加（接进了 `npm run lint`）。
- 组件里用 `useT()`：`const { t, lang } = useT()`；普通 TS 模块用 `translate(currentLang(), key, params)`。
- 组 / 站点 / 特性条目的数据文案走各自的可选 `i18n` 字段（`pickLocalized`），缺项回落根语言。
- `theme.*` 前缀保留给主题词汇，现在不要往里加键。

## 5. `SITE_URL`

`.env` 或真实环境变量里的 `SITE_URL`（完整地址，如 `https://lectures.example.org`），私有站留空。

- 设置后：生成 `sitemap.xml`；每个存在于两种以上语言的页面写 `hreflang`（含自身与 `x-default` → 根语言版本）。
- 不设：两者都不生成。
- 构建后 `npm run check:i18n:dist` 按这一条件校验：译文页、英文搜索索引不含中文正文、hreflang / sitemap。

## 6. 读者看到什么

- **语言切换**：顶栏（手机上在导航面板里）显示另一种语言的自称（`中文` / `English`），是真实链接。去向：讲义有译本去译本，没有去该语言的本组页；组页去同一组；其余去该语言首页。点击时记住读者语言（`localStorage['lecture-reader-lang']`）。
- **读者语言偏好**：用切换器、或打开任何非根语言页面时写入；只用来决定提示条，不跳转。
- **提示条**（根语言讲义页，偏好是非根语言时才出现，挂载后渲染，不影响水合）：有译本显示「这一讲有译本」和链接；没有译本说明正在读原文，给出回到该语言课程页的链接和「继续阅读中文」按钮，点后偏好改回根语言，提示条不再出现。文字用读者语言的字典。
- **组页计数**：非根语言组页显示「已译 N / 共 M 讲」，根语言组页不变。
- **导出按钮**：非根语言讲义页不显示（导出产物按根语言路径预生成，译文导出以后再做）。

## 7. 还没做

- 图表节点文字的多语言（图表数据里的 `labels.en`）。
- 主题词汇 `theme.*`（地图皮肤等，P4 跟第一个使用方一起落地）。
- 每种语言单独的容器 / 栏目标题：需要 VitePress 2。
- 搜索引擎抓取策略（`robots`，P3）。
- 未迁移字典的组件（`GlobalCurriculumMap`、`GroupKnowledgeMap`、`ai/*`）在英文页上暂时还是中文。
