# 讲义内容标准化写作规范 (Content Specification)

> **适用范围**：所有接入开源讲义引擎的课程内容源（Content Packages）。  
> **核心原则**：高质感工程直觉、严格排版一致性、Vue 模板编译安全、全站无裸外链。

---

## 1. Frontmatter 元数据契约

每一篇讲义 Markdown 文件（如 `L01.md`）必须以 YAML frontmatter 开头，且必须遵循以下格式规范：

```yaml
---
title: "第01讲 · 引擎渲染与图表体系"
order: 1
description: "节点 `demo_echarts_rendering` ｜ 亚组: DEMO ｜ 难度 ★★ ｜ 预估 20min ｜ 前置: demo_curriculum_overview ｜ 后续: demo_mermaid_architecture"
outline: deep
---
```

### 硬性指标：
- **`title` 必须使用英文双引号包裹**：防止标题中包含中文冒号（`：`）或特殊符号时引起 YAML 解析异常；
- **`description` 中必须保留 `节点 \`notion_node_id\``**：保证从讲义到知识图谱节点的双向溯源链路；
- **`outline: deep`**：开启右侧大纲多级展示。

---

## 2. 外部链接规范：全站严禁裸外链，唯一合法形态为 `.cite` 胶囊

### 2.1 核心原则
- **严禁出现任何原生 Markdown 链接 `[文字](URL)` 或裸 URL**（蓝色+下划线会严重破坏沉浸式阅读节奏）；
- **「## 参考来源」段已全站彻底废除**：严禁在文末追加长串参考书目列表；
- 外部文献或权威手册应作为佐证直接就地嵌入正文论述。

### 2.2 胶囊标准语法
```html
<span class="cite" data-cite="https://vitepress.dev" title="https://vitepress.dev">VitePress 官方指引</span>
```
- **视觉特性**：平时呈现为灰底浅色小胶囊（chip），悬停展示品牌色并在新标签页打开；
- **清理规则**：若括号内含有来源标注，应保留中文说明，清理 URL 并转为胶囊。

---

## 3. 数学公式规范 (KaTeX)

站点采用构建期 KaTeX 渲染，严禁使用 ASCII 字符硬摆版或过时的 `math` 代码围栏。

### 3.1 分隔符契约
- **行内公式**：使用 `\( … \)`（禁用裸 `$…$`，避免与价格 `$100` 或 Shell 变量冲突）；
- **行间公式**：使用 `$$ … $$`（独立成行，前后各保留一个空行）。

### 3.2 分式与单位排版
- **定义式与量关系**：使用 `\dfrac`（满尺寸上下结构）：
  $$
  C = \dfrac{Q}{V}, \quad I = \dfrac{\Delta Q}{\Delta t}
  $$
- **系数与小分式**：使用 `\frac`：
  $$
  U = \frac{1}{2} C V^2
  $$
- **单位与指数表达式**：保留斜杠（SI 国际单位制规范）：
  $$
  1\,\mathrm{V} = 1\,\mathrm{J/C}, \quad e^{-t/\tau}
  $$

## 4. Vue 模板编译器安全规约

讲义正文由 VitePress 编译为 Vue SFC 组件，必须遵守以下安全防线：

1. **尖括号安全**：
   - 散文中 `<` 紧跟 ASCII 字母/下划线时，必须转义为 `&lt;`（如 `&lt;stdio.h>`、`&lt;int>`），防止 Vue 误判为未闭合的 HTML 标签；
   - 散文中 `<` 紧跟数字、空格或中文时保持原样（如 `< 150`）；
   - 行内代码 span 中的占位符直接去掉尖括号，改写为 `` `name` ``。
2. **双花括号打断**：
   - 散文或代码中若出现连续 `{{` 或 `}}`，必须插入零宽空格（`\u200b`），防止被 Vue 模板插值解析器误拦截。
3. **Setext 标题防护**：
   - 分隔线 `---` 前面必须强制保留一个空行，防止上一段文本被误解析为二级标题。

---

## 5. 全篇结尾标准化契约：「## 下一讲预告」

每一篇讲义的正文末尾，**必须以独立的二级标题 `## 下一讲预告` 作为全篇压轴收束**：

```markdown
---

## 下一讲预告

在接下来的篇章中，我们将进入实操讲解，深入剖析图表组件的渲染机制与状态注入链路。

下一讲我们将学习：**第01讲 · 引擎渲染与图表体系**（节点标识符：`demo_echarts_rendering`）。
```

### 三要素要求：
1. **承上**：对本讲的核心物理直觉与系统结论做精炼收束；
2. **启下**：提出过渡到下一层级系统工程的探索性设问；
3. **节点锚定**：显式包含下一讲的完整中文标题与行内代码样式的英文节点标识符。

---

## 6. 课程体系动态隔离机制 (Dynamic Example Fallback & Exclusive Isolation)

- **开箱即用（无讲义态）**：未载入任何个人讲义时，引擎加载 `site/docs/examples/` 下 6 大演示课程（计算机系统、运行时、网络、分布式、存储、云原生），作为开箱即用的功能展示与结构样板；
- **个人独占（有讲义态）**：一旦检测到个人讲义（无论是挂载还是本地配置 `groups.mts`），引擎**自动屏蔽并卸载示例目录**，并通过 VitePress `srcExclude: ['examples/**']` 在编译期排除示例 Markdown，保证本地搜索、侧边栏、导航与脑图 100% 独占呈现用户个人课程体系。
