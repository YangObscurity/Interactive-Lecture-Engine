# 功能验证 · 引擎特性自测台

> 本页是**交互式讲义引擎的核心特性自检基准页**，属于 `site/docs/examples/` 示例集。
> 涵盖图表交互、矢量波形、公式排版、引用胶囊、沉浸阅读、多主题自愈与多格式导出等核心特性的端到端检验。

## 这个页面为什么存在

引擎的自动化闸门（`scripts/audit_all.py` 等）验证的是**构建产物与内容契约**：图表锚点守恒、
外链硬判据、公式分隔符。它们不回答「浏览器里点一下会怎样」。

于是有一类缺陷只有真跑才看得见，例如：

- 图表渲染是**异步**的（约 3 秒），截图脚本若不等 `window.__CHARTS_DONE__` 就会拍到空框；
- `.cite` 胶囊点击必须**新开标签页**且**不跳文末**；
- 沉浸式阅读要真的让导航与大纲收起、版心变宽，并且**刷新后仍然记得**；
- 暗色模式下 mermaid 渲染出的 SVG **不继承页面 CSS 变量**，必须由主题显式注入配色。

本页把这些项目集中成一份可逐条勾选的清单，配合 CDP 脚本即可做真实数值断言。

## 自动化 ABI（外部观测者依赖，不可变更）

以下符号是**自动化截图与闸门依赖的公共接口**。改动它们等同于破坏外部契约：

| 符号 | 类型 | 语义 |
| :--- | :--- | :--- |
| `window.__CHARTS_DONE__` | `boolean` | 本页全部图表渲染结束（成功或失败都会置位）。渲染前为 `false` |
| `figure.chart[data-chart-status]` | `string` | `loading` → `ok` / `missing` / `error` / `unknown-type` |
| `figure.chart[data-toolsBound]` | `'1'` | 工具条已绑定（三类图都会设，恒等于 figure 数） |
| `figure.chart[data-fitBound]` | `'1'` | 内联自适应已绑定（**仅矢量图** mermaid / wavedrom 设，echarts 按设计不设） |
| `figure.chart[data-rendered]` | `'1'` | 该 figure 已被运行时接管 |

::: warning 等待图表的正确姿势
`__CHARTS_DONE__` 约需 **3 秒**才变 `true`。任何截图或断言都必须**轮询**它，
否则会拍到「图表源缺失」空框 —— 这是本项目实测踩过的坑。
:::

### 2. KaTeX 公式

行内公式（应随正文行距均匀排布，不顶高行高）：欧姆定律 \( I = \dfrac{U}{R} \)。

行间公式（独立成块，点击可复制 LaTeX 源码）：

$$ R = \dfrac{U_{\text{电源}} - U_{\text{LED}}}{I_{\text{目标}}} $$

**期望**：`.katex` 节点数 > 0、`.katex-display` ≥ 1、`.math-node` 带有 `data-tex`；
**KaTeX 字体请求 0 个 403**（字体缺失会导致公式渲染成方框，但仍不报错——所以必须查网络）。

### 3. `.cite` 引用胶囊

外部链接的唯一合法形态是胶囊，禁止原生 Markdown 链接与裸 URL：

<span class="cite" data-cite="https://developer.mozilla.org/zh-CN/docs/Web/API/Canvas_API" title="https://developer.mozilla.org/zh-CN/docs/Web/API/Canvas_API">MDN · Canvas API 参考</span>

<span class="cite" data-cite="https://mermaid.js.org/intro/" title="https://mermaid.js.org/intro/">Mermaid 官方文档</span>

**期望**：`.cite` 元素存在；点击后**新标签页打开 `data-cite`**，且**当前页不跳转**（不跳文末）。

### 4. 沉浸式阅读

点击顶栏的「沉浸阅读」按钮。

**期望**：
- `html` 上出现 `reading-mode` 类，按钮 `aria-pressed` 变 `true`、文案变「退出沉浸」；
- `.VPSidebar` 与 `.VPDocAside` 收起（`display` 变 `none`，宽度归 0）；
- `.vp-doc` 版心**明显变宽**（实测 688px → 1242px）；
- 写入 `localStorage['lecture-reading-mode'] = '1'`，**刷新后保持**。

### 5. 阅读进度记忆

滚动到本页中段，然后刷新。

**期望**：刷新后自动回到上次位置，并出现「已回到上次阅读位置 · N%」提示条；
`localStorage['lecture-read-pos']` 内有 `{ y, pct, title, group, ts }`。

::: tip 测试时的坑
`reading-progress.ts` **只认真实手势**（`wheel` / `touchstart` / `keydown` / `mousedown`）
才算「用户接管」。用 `window.scrollTo()` 这类**程序化滚动**会被有意忽略，
因此自动化脚本必须发真实输入事件（CDP 的 `Input.dispatchMouseEvent`，`type: mouseWheel`），
否则会误判成「进度记忆失效」。
:::

### 6. 暗色模式图表重绘

点击右上角主题切换按钮切到暗色。

**期望**：`html.dark` 出现、`--vp-c-bg` 由 `#ffffff` 变 `#1b1b1f`；
**mermaid / wavedrom 的 SVG 内联 `fill` / `stroke` 属性真的发生变化**
（因为 SVG 不继承 CSS 变量，必须由 `initialize({ themeVariables })` 显式注入）；
切换后三张图仍全部 `ok`。

### 7. 脑图

脑图位于首页与课程组页（`GlobalCurriculumMap.vue` / `GroupKnowledgeMap.vue`）。

**期望**：节点与连线渲染出 SVG；`.smm-expand-btn` / `gc-action-btn` 可折叠且高度收拢；
**在脑图上滚动不得劫持页面滚动**（`window.scrollY` 必须跟着变）。

### 8. AI 侧栏

点击右侧「AI 伴读」标签页。

**期望**：侧栏展开（`html.has-ai-split`）、出现输入框；发问后**有回复**（本地 Mock 降级路径）。

::: tip 默认运行环境说明
在未配置外部后端服务时：
- AI 伴读自动启用 **本地 Mock 模拟回复**（`/api/ai/chat` 404 为预期降级行为）；
- 全景脑图展示示例内容源（节点规模依据示例讲义数量动态渲染）；
- 会话持久化接口自动降级为本地内存临时会话。
:::
