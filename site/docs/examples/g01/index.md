# 示例课程 · 引擎自带的原创示例内容源

> 本课程组是**引擎开箱即用的基准示例**。展示标准讲义结构、双向图表锚点绑定及全量前端渲染能力。

## 示例课程组的设计定位

本仓库采用**内容与引擎物理彻底分离**的设计架构。引擎核心（主题系统、图表运行时、数学排版、构建管线）具备完全的通用性，不与任何特定业务课程绑定。

为了保证开箱即用体验（克隆后可直接 `npm run dev` / `npm run build` 成功），本示例提供了**最小内容源**：自带规范的示范正文与配套图表 sidecar，方便开发者直观预览和进行二次开发。

::: tip 接入自定义课程
若需装载您的自有课程，请参考 `content/CONTENT_SOURCE.md` 契约建立内容源，
通过 `python scripts/mount_content.py --mount <课程源>` 即可完成一键挂载接入。
本示例目录（`site/docs/examples/`）属于引擎基线，挂载时不会被覆盖。
:::

## 示例演示了什么

`L01` 一讲即覆盖引擎的全部核心特性，逐项可对照阅读：

| 特性 | 在 L01 中的落点 | 说明 |
| :--- | :--- | :--- |
| mermaid 流程图 | `#c1` | 关系图 / 流程图，内联可点开全屏 |
| echarts 数据图 | `#c2` | 悬停看数值、点图例开关数据线 |
| wavedrom 时序图 | `#c3` | 波形 / 时序，全屏内缩放拖动 |
| 行内 LaTeX | 欧姆定律处 | 构建期 KaTeX 渲染，点击可复制源码 |
| 行间公式 | 功耗推导处 | `$$ … $$` 独立成块 |
| `.cite` 引用胶囊 | 全篇 2 处 | 外链唯一合法形态，点击新标签页打开 |
| 代码高亮 | 计算示例处 | Shiki 高亮，语言标签用规范值 |
| 收尾契约 | 文末 | 必须以 `## 下一讲预告` 作压轴二级标题 |
