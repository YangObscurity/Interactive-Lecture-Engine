# Lecture 5 · Counterexamples and Proof by Contradiction

## Key points

One [counterexample](concept:counterexample) is enough to refute an "every ... is ..." statement. To prove a statement, you can assume it is false and derive a contradiction: proof by contradiction. Both rest on how a [quantifier](concept:quantifier) is negated.

## Explanation

### Why one counterexample is enough

The negation of \(\forall x,\ P(x)\) is \(\exists x,\ \neg P(x)\). Finding one x for which P fails proves the negation, so the original statement is false. Many examples, on the other hand, never prove a universal statement; they only show that no counterexample has been found yet.

### What a good counterexample looks like

It meets every hypothesis of the statement, fails only the conclusion, and is easy to check. For "every prime is odd" it is 2: a prime, and not odd.

### Steps of a proof by contradiction

1. Assume the conclusion is false.
2. Reason step by step with valid rules.
3. Reach a contradiction with a known fact or with the assumption itself.
4. The assumption must be wrong, so the conclusion holds.

## Example

### Forty examples are not enough

Take \(f(n) = n^2 + n + 41\). For n from 0 to 39 every value is prime, which tempts us to claim it for every n. But

$$
f(40) = 40^2 + 40 + 41 = 40 \times 41 + 41 = 41 \times 41 = 1681
$$

is not prime. The chart shows n = 34 to 41; the two red bars are composite, and f(41) = 1763 = 41 × 43 as well.

### A proof by contradiction

Claim: if \(n^2\) is even, then n is even. Suppose n is odd, \(n = 2k + 1\). Then

$$
n^2 = 4k^2 + 4k + 1 = 2(2k^2 + 2k) + 1
$$

is odd, contradicting "\(n^2\) is even". So n is even.

| Aspect | Counterexample | Contradiction |
|---|---|---|
| Used to | refute a universal statement | prove a statement |
| Needs | one object meeting the hypotheses and failing the conclusion | a contradiction derived from the negated conclusion |

## Common mistakes

- **"Proving" a universal statement with examples**: forty examples can still be overturned by the forty-first.
- **A counterexample that misses a hypothesis**: 9 does not refute "every prime is odd", because 9 is not prime.
- **No real contradiction**: a surprising result is not a contradiction; it has to clash with a known fact or the assumption.

:::: details Self-check

**Question 1**　Find a counterexample to "for every n ≥ 2, \(2^n - 1\) is prime".

::: details Answer
n = 4: \(2^4 - 1 = 15 = 3 \times 5\), which is not prime.
:::

**Question 2**　Prove by contradiction: if \(n^2\) is odd, then n is odd.

::: details Answer
Suppose n is even, \(n = 2k\). Then \(n^2 = 4k^2 = 2(2k^2)\) is even, which contradicts \(n^2\) being odd, so n is odd.
:::

**Question 3**　Someone says "I tried 100 numbers and it held every time, so it holds for all numbers". What is wrong with this reasoning?

::: details Answer
Examples only show that no counterexample has turned up yet; they cannot replace an argument that covers every case. The 101st number could be the counterexample.
:::
::::

## Summary

- One counterexample that meets the hypotheses and fails the conclusion refutes a universal statement.
- A proof by contradiction assumes the conclusion is false and derives a contradiction.
- Both rely on negating a quantifier: "not every" equals "there is one that does not".
