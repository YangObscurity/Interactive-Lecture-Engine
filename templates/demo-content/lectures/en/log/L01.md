# Lecture 1 · Propositions and Truth Tables

## Key points

A proposition is a statement that is either true or false. "It is raining today" is one; "please close the door" is not.

Concept used here: [truth table](concept:truth-table).

<figure class="chart" data-lecture="LOG-L01" data-id="c1" data-type="wavedrom"></figure>

## Example

Join propositions with and, or and not, and a truth table lists every combination.

<LectureFigure id="log-and-gate" />

As [](fig:log-and-gate) shows, "and" is true only when both sides are true.

## Summary

- A proposition is a statement that is either true or false.
