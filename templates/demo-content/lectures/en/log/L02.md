# Lecture 2 · Conditionals and Contrapositives

## Key points

"If P then Q" is false only when P is true and Q is false.

## Example

A conditional and its contrapositive "if not Q then not P" are always true or false together.

## Summary

- "If P then Q" is false only when P is true and Q is false.
