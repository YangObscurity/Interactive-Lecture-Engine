# 第2讲 · 坐标轴与刻度

> 节点 `vis_axes` ｜ 亚组: VIS（图表与可视化） ｜ 难度 ★★ ｜ 预估 25min ｜ 前置: vis_choose、mea_plots ｜ 后续: vis_mislead

## 要点

坐标轴是读者把图形换算回数字的尺子。条形图用长度编码数值，纵轴必须从 0 开始；折线图用位置编码数值，可以不从 0 开始，但要让读者看得出来。数值跨越好几个数量级时，对数刻度能把“倍数关系”变成等距的台阶。

## 讲解

### 条形的长度就是数值

条形图里，读者比较的是条形的长度。如果纵轴从 96 开始，97.2 画出来的长度只有 1.2 格，98.6 却有 2.6 格，看上去差了一倍多。可以用一个式子估计这种“视觉放大”：设纵轴起点为 \( m \)，两个数值为 \( a \lt b \)，

$$
\text{看起来的倍数} = \frac{b - m}{a - m}, \qquad \text{真实的倍数} = \frac{b}{a}.
$$

当 \( m \) 越接近 \( a \)，分母越小，看起来的倍数就越夸张。所以条形图的纵轴要从 0 开始，让长度如实对应数值。

### 折线图可以放大局部，但要说明

折线图里，读者看的是点的高低和线的走向，不是从基线量出来的长度。体温在 36.2 °C 到 37.4 °C 之间波动，如果纵轴从 0 开始，整条线会被压成一条直线，什么也看不出来。这时把纵轴设在 35 °C 到 38 °C 是合理的，但要满足两点：刻度数字清楚标出，图题或说明里不暗示“翻了几倍”。

### 刻度要均匀，单位要写全

一条坐标轴上相邻刻度的间距应当代表相同的数值差。测量与估算组第 5 讲“读图与插值”里练过的估读，就依赖这一点：只有刻度均匀，才能在两个刻度之间按比例估读。轴的名称要写上量和单位，比如“满意度（%）”“时间（h）”，不要只写一个“数值”。

### 对数刻度：每一格乘同一个数

在对数刻度上，从 10 到 100、从 100 到 1000 占据相同的距离，每一格代表“乘以 10”。数量按固定倍数增长时（例如每 2 小时翻一倍），在普通刻度上是一条越来越陡的曲线，在对数刻度上却是一条直线，斜率对应增长的快慢。

<figure class="chart" data-lecture="VIS-L02" data-id="c3" data-type="echarts"></figure>

对数刻度的代价是：读者不能再直接用“长度”比较差值，而且它不能表示 0 和负数。使用时一定在轴名称里注明“对数刻度”。

## 例子

三家门店的顾客满意度分别是 97.2%、98.1%、98.6%。先看纵轴从 96 开始的条形图：

<figure class="chart" data-lecture="VIS-L02" data-id="c1" data-type="echarts"></figure>

按上面的式子，丙店与甲店“看起来的倍数”是 \( (98.6-96)/(97.2-96) = 2.6/1.2 \approx 2.2 \)，而真实的倍数只有 \( 98.6/97.2 \approx 1.014 \)。再看纵轴从 0 开始的版本：

<figure class="chart" data-lecture="VIS-L02" data-id="c2" data-type="echarts"></figure>

三根条形几乎一样高，这才是事实：三家店的满意度都很高，差距不到 1.5 个百分点。如果真想强调这点差距，更好的做法是换一种图，比如直接画“与平均值的差”，并在纵轴上写明“百分点”。

```python
# 示例：纵轴起点造成的视觉放大
def apparent_ratio(a, b, m):
    return (b - m) / (a - m)

print(round(apparent_ratio(97.2, 98.6, 96), 2))  # 2.17
print(round(apparent_ratio(97.2, 98.6, 0), 3))   # 1.014
```

## 常见误区

- **条形图截断纵轴**：长度不再与数值成正比，小差距被放大成大差距。
- **刻度不均匀**：为了“挤下”某个特别大的值而在中途改变刻度间隔，读者按比例估读就会出错。真有特别大的值，应换成对数刻度或单独标注。
- **省略单位**：“增长 3” 是 3 个百分点还是 3%？轴名称和图题里都要写清楚。

:::: details 自测题

**第 1 题**　一张条形图的纵轴从 50 开始，两根条形对应 60 和 80。看起来后者是前者的几倍？真实是几倍？

::: details 答案
看起来 \( (80-50)/(60-50) = 3 \) 倍，真实 \( 80/60 \approx 1.33 \) 倍。
:::

**第 2 题**　记录一周每天的室温（19 °C 到 23 °C），用折线图时纵轴一定要从 0 开始吗？

::: details 答案
不一定。折线图看的是位置和走向，可以把纵轴设在 18 °C 到 24 °C，只要刻度数字标清楚。
:::

**第 3 题**　什么样的数据适合用对数刻度？举一个例子。

::: details 答案
数值跨越几个数量级、或者按固定倍数增长的数据，例如每代翻倍的个体数、不同规模城市的人口。
:::
::::

## 小结

- 条形图用长度编码数值，纵轴从 0 开始；截断会把差距放大到 \( (b-m)/(a-m) \) 倍。
- 折线图可以缩放纵轴看清起伏，但刻度要标清，结论里不能暗示倍数。
- 刻度均匀、单位写全；倍数增长的数据用对数刻度，并在轴名称里注明。
