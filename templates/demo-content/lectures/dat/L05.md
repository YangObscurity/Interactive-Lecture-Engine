# 第5讲 · 可复现的整理流程

> 节点 `dat_repro` ｜ 亚组: DAT（表格与数据整理） ｜ 难度 ★★★ ｜ 预估 30min ｜ 前置: dat_pivot ｜ 后续: exp_record

## 要点

一个整理结果“可复现”，是指别人拿到同一份原始文件和你的步骤说明，能一步步得到完全相同的结果。做到这一点只需要三条习惯：原始文件只读，每一步都写下来，每一步都留一个可以核对的数字。

## 讲解

### 为什么手工整理难以复现

在表格里手工删几行、改几个格子、拖一拖公式，结果当时看起来没问题。可一个月后有人问“这个 6200 是怎么来的”，你很可能已经想不起删了哪几行、为什么删。更糟的是，原始文件可能已经被这些操作改掉了，连重来一遍的机会都没有。

### 三条习惯

1. **原始文件只读**：拿到数据后先存一份原样，之后的所有操作都在副本上进行，或者由步骤自动生成新文件。原始文件就像实验的原始记录，不能涂改。
2. **每一步都写下来**：可以是一段脚本，也可以是一份按顺序编号的操作清单。关键是“照着做就能重来”，而不是“我记得大概是这样”。
3. **每一步留一个核对数字**：记录每一步之后的行数、缺失个数或合计值。重做一遍时，这些数字一致，才说明结果真的被复现了。

### 说明文件写什么

在结果旁边放一份简短的说明：数据从哪里来、什么时候取得、每一列是什么意思和单位、空格代表什么（见第 3 讲的[缺失值](concept:missing-value)）、整理分了哪几步。文件名带上日期或版本号，例如 `借阅记录_原始_第3周.csv`、`借阅记录_透视_v2.csv`，不要用“最终版”“最终版2”。

## 例子

把前两讲的借阅数据整理流程固定下来，每一步记录核对数字：

| 步骤 | 做了什么 | 之后的行数 | 核对 |
|---|---|---|---|
| 0 | 读入原始文件（只读） | 128 | 与来源说明的 128 条一致 |
| 1 | 统一班级写法、日期格式 | 128 | 班级只剩 3 种写法 |
| 2 | 删除重复记录 | 125 | 删除 3 条，原因写入记录 |
| 3 | 标记缺失的借阅量 | 125 | 缺失 2 条，不参与求和 |
| 4 | 按班级、月份分组求和 | 9 | 合计 327 本 |
| 5 | 透视成班级 × 月份 | 3 | 行合计之和 = 列合计之和 = 327 |

一周后数据提供者发来一份补充了 4 条记录的新原始文件。因为步骤是写好的，只要把步骤 0 换成新文件，从头再跑一遍：行数变成 132、129、129……合计更新为新的值，前后两次的差别一目了然，不需要重新回忆当初做了什么。

```python
# 示例：每一步都返回新表，并打印核对数字
def dedupe(rows):
    seen, out = set(), []
    for r in rows:
        if r not in seen:
            seen.add(r)
            out.append(r)
    return out

raw = [("一班", "3月", 2), ("一班", "3月", 2), ("二班", "3月", None)]  # 原始数据不修改
step1 = dedupe(raw)
step2 = [r for r in step1 if r[2] is not None]
print(len(raw), len(step1), len(step2))  # 3 2 1
```

## 常见误区

- **在原始文件上直接改**：一旦改错，就再也回不到起点。原始文件应该从拿到那一刻起只读。
- **步骤只存在脑子里**：口头的“先去重再求和”不够，顺序、条件、删了哪些都要写下来。
- **只看最终结果对不对**：中间步骤没有核对数字，最终结果碰巧对上也可能是两个错误互相抵消。

:::: details 自测题

**第 1 题**　为什么说“原始文件只读”是可复现的前提？

::: details 答案
只有起点不变，别人按同样的步骤才可能得到同样的结果；起点被改过，复现就无从谈起。
:::

**第 2 题**　本讲例子中，步骤 2 之后的行数从 128 变成 125，应该在记录里写清楚哪些信息？

::: details 答案
删除了 3 条、依据是什么（例如所有列都相同）、具体是哪 3 条。
:::

**第 3 题**　两个人用同样的原始文件和步骤清单，得到的合计一个是 327、一个是 329。你会先检查什么？

::: details 答案
逐步对照两人的核对数字，找到第一个不一致的步骤，问题就出在那一步。
:::
::::

## 小结

- 可复现指别人用同样的原始文件和步骤，能得到完全相同的结果。
- 三条习惯：原始文件只读，每一步写下来，每一步留核对数字。
- 结果旁放说明文件：来源、日期、列的含义与单位、空格的含义和整理步骤。
