# 第3讲 · 缺失值与清洗

> 节点 `dat_clean` ｜ 亚组: DAT（表格与数据整理） ｜ 难度 ★★ ｜ 预估 25min ｜ 前置: dat_tidy ｜ 后续: dat_pivot

## 要点

真实的表格总有空格、写法不一、单位混用和重复记录。清洗就是在汇总之前把这些问题找出来、处理掉，并把每一步记下来。处理[缺失值](concept:missing-value)的第一原则是：先问它为什么是空的，再决定怎么办，绝不悄悄填 0。

## 讲解

### 常见的四类“脏”

| 问题 | 例子 | 后果 |
|---|---|---|
| 缺失 | 某天的读数是空的 | 求平均时被当成 0 会拉低结果 |
| 写法不一 | “二班”“2班”“二 班” | 分组时被当成三个不同的班 |
| 单位混用 | 有的写 1.2 kg，有的写 1200 g | 直接相加得到毫无意义的数 |
| 重复记录 | 同一条记录录入了两次 | 计数和求和偏大 |

第一讲说过，整齐的表格每个格子只放一个值，每一列是一个变量。清洗的目标就是让表格重新满足这几条规则，回到[整洁数据](concept:tidy-data)的形状。

### 缺失值：先问为什么

同样是空格，原因可能完全不同，处理方式也不同：

<figure class="chart" data-lecture="DAT-L03" data-id="c1" data-type="mermaid"></figure>

- **本来就没有**：例如“第二联系人”一栏，很多人确实没有。保留为空，在说明里写明“空 = 无”。
- **漏记或丢失**：例如设备没电导致某天没有读数。标记为“缺失”，统计时排除并报告排除了几条；能从其他来源补回的就补回，并注明来源。
- **录入错误**：例如把数值敲进了隔壁一列。回到原始记录核对，改正后在清洗记录里写下改了哪一格。

### 为什么不能填 0

0 是一个真实的测量结果，空格的意思是“不知道”。设一列有 \( n \) 个有效读数、总和为 \( S \)，另有 \( k \) 个缺失。把缺失当成 0 求平均，得到的是

$$
\frac{S}{n + k} \quad \text{而不是} \quad \frac{S}{n},
$$

缺失越多，结果偏低得越厉害。正确的做法是只用有效读数求平均，并同时报告有效读数的个数。

## 例子

一个兴趣小组记录了一周的每日步数，原始表如下（“—”表示空格）：

| 日期 | 成员 | 步数 | 备注 |
|---|---|---|---|
| 周一 | 小甲 | 8 200 | |
| 周一 | 小甲 | 8 200 | 重复录入 |
| 周二 | 小甲 | — | 手环没电 |
| 周三 | 小甲 | 0 | 生病卧床 |
| 周四 | 小甲 | 7.5千 | |
| 周五 | 小甲 | 9 100 | |

逐条处理：周一的第二行是重复记录，删除；周二是“漏记”，标记为缺失；周三的 0 是真实值（确实没走路），保留；周四的“7.5千”统一写成 7 500。清洗后的有效读数是 8 200、0、7 500、9 100，共 4 条：

$$
\bar x = \frac{8200 + 0 + 7500 + 9100}{4} = 6200 \text{ 步}.
$$

如果把周二的空格当 0、又没删除重复的一行，就会用 6 个数求平均，得到 \( 33000 / 6 = 5500 \) 步，比正确结果少了 700 步。

```python
# 示例：只用有效读数求平均，并报告缺失个数
steps = [8200, None, 0, 7500, 9100]   # 已去重、已统一写法；None 表示缺失
valid = [x for x in steps if x is not None]
print(sum(valid) / len(valid), "有效", len(valid), "缺失", steps.count(None))
```

## 常见误区

- **把空格和 0 混为一谈**：0 是测到了“没有”，空格是没测到。两者必须在表里用不同的方式表示。
- **直接改原始文件**：清洗应当在副本上进行，原始文件保持原样，否则出错后无从追查。
- **悄悄删行**：删掉了几行、为什么删，都要写进清洗记录，并在汇总结果旁注明有效样本量。

:::: details 自测题

**第 1 题**　一列体重数据里，有的写“52 kg”，有的写“52000 g”，应该怎样清洗？

::: details 答案
统一成同一个单位（例如 kg），把单位写在列名里，格子里只留数字。
:::

**第 2 题**　一份问卷中“过敏药物”一栏大多是空的，能否直接当作缺失值排除？

::: details 答案
不一定。很多人确实没有过敏药物，这时空格的含义是“无”，应该在说明中注明，而不是当作“不知道”。
:::

**第 3 题**　有效读数 10、12、14，另有 2 个缺失。错误地把缺失当 0，平均值会是多少？正确的是多少？

::: details 答案
错误：\( 36 / 5 = 7.2 \)；正确：\( 36 / 3 = 12 \)。
:::
::::

## 小结

- 常见的脏数据有四类：缺失、写法不一、单位混用、重复记录。
- 处理缺失值先问原因：本来没有、漏记丢失、录入错误，各有不同做法，绝不填 0。
- 在副本上清洗，把每一步写进清洗记录，并报告有效样本量。
