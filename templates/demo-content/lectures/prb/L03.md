# 第3讲 · 期望值

> 节点 `prb_expect` ｜ 亚组: PRB（概率与统计入门） ｜ 难度 ★★ ｜ 预估 25min ｜ 前置: prb_freq ｜ 后续: prb_dist

## 要点

[期望值](concept:expected-value)是把每种可能结果乘上它的概率再加起来得到的数，代表"重复很多次以后平均每次得到多少"。它不一定是某一次真能出现的结果，却是比较不同选择时最常用的标尺。

## 讲解

### 加权平均

一个随机量 \(X\) 可能取 \(x_1, x_2, \dots, x_k\)，对应概率 \(p_1, p_2, \dots, p_k\)（加起来等于 1），它的期望值是

$$
E[X] = \sum_{i=1}^{k} x_i\,p_i
$$

掷一颗均匀骰子，点数的期望是 \((1+2+3+4+5+6)/6 = 3.5\)。没有哪一面写着 3.5，但掷一万次，点数的平均会非常接近 3.5。这和上一讲的频率是同一个道理：概率是频率的极限，期望就是平均值的极限。

### 为什么它有用

做决定时，单看"最好情况"或"最坏情况"都会偏。期望值把所有情况连同各自的可能性一起算进去。买保险、选路线、定库存，背后都有一笔期望账：每次多花一点确定的成本，换掉一个小概率的大损失。

### 两条好用的性质

- **线性**：\(E[aX + b] = a\,E[X] + b\)，\(E[X + Y] = E[X] + E[Y]\)。后一条不要求 \(X\)、\(Y\) 独立。两颗骰子点数之和的期望就是 \(3.5 + 3.5 = 7\)，不用列 36 种情况。
- **期望不说明波动**：两个选择期望相同，风险可以差很多。衡量波动要用方差 \(\mathrm{Var}(X) = E[(X - E[X])^2]\)，它的平方根就是标准差，在测量课的[平均值与离散程度](../mea/L04.md)里已经见过。

## 例子

集市上有个游戏：付 2 元掷一次骰子，掷到 6 得 8 元，掷到 5 得 3 元，其他点数什么也没有。值得玩吗？

| 点数 | 得到的钱 \(x\) | 概率 \(p\) | \(x \cdot p\) |
|---|---|---|---|
| 6 | 8 | 1/6 | 1.333 |
| 5 | 3 | 1/6 | 0.500 |
| 1–4 | 0 | 4/6 | 0 |
| 合计 | | 1 | 1.833 |

每局平均拿回约 1.83 元，付出 2 元，所以**净收益的期望**是 \(1.833 - 2 \approx -0.17\) 元。玩 300 局，大约会亏 50 元。单局可能赢 6 元，但长期一定是摊主占便宜。

可以用一小段模拟验证：

```python
import random

def play():
    d = random.randint(1, 6)
    return {6: 8, 5: 3}.get(d, 0) - 2

n = 100_000
print(sum(play() for _ in range(n)) / n)   # 约 -0.17
```

## 常见误区

- **"期望值是最可能出现的结果。"** 上面的游戏里，最常见的结果是净输 2 元（概率 2/3），期望却是 -0.17 元。期望是长期平均，不是众数。
- **只看期望不看风险。** 一个方案期望略高但有 1% 的可能让你倾家荡产，未必比期望略低、稳稳当当的方案好。
- **把期望用在只发生一次的事上而忘了波动。** 期望在多次重复时才兑现；只做一次时，要同时看分布。

:::: details 自测题

**第 1 题**　一张抽奖券 5 元，1000 张里有 1 张中 2000 元、10 张中 100 元，其余不中。一张券的净收益期望是多少？

::: details 答案
奖金期望 \(2000 \times 0.001 + 100 \times 0.01 = 2 + 1 = 3\) 元，净收益期望 \(3 - 5 = -2\) 元。
:::

**第 2 题**　\(X\) 是一颗骰子的点数，求 \(E[2X + 1]\)。

::: details 答案
\(2 \times 3.5 + 1 = 8\)。
:::

**第 3 题**　两个方案的期望收益都是 100 元：A 一定得 100 元；B 一半可能得 0 元，一半可能得 200 元。它们的方差哪个大？

::: details 答案
A 的方差是 0；B 的方差是 \(0.5 \times 100^2 + 0.5 \times 100^2 = 10000\)，B 大得多。
:::
::::

## 小结

- 期望值 \(E[X] = \sum x_i p_i\)，是按概率加权的平均，也是大量重复下的平均。
- 期望是线性的：和的期望等于期望的和，不要求独立。
- 期望相同不代表风险相同，还要看方差或标准差。
