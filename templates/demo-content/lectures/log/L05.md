# 第5讲 · 反例与归谬

> 节点 `log_counter` ｜ 亚组: LOG（逻辑与推理） ｜ 难度 ★★★ ｜ 预估 30min ｜ 前置: log_proofs、log_sets ｜ 后续: prb_corr

## 要点

要推翻"所有……都……"，一个[反例](concept:counterexample)就够；要证明一个命题，可以先假设它不成立，再推出矛盾，这叫归谬（反证法）。两者都建立在上一讲[量词](concept:quantifier)的否定规则上。

## 讲解

### 反例为什么有分量

全称命题 \(\forall x,\ P(x)\) 的否定是 \(\exists x,\ \neg P(x)\)。找到一个让 P 不成立的 x，就证明了否定成立，原命题为假。反过来，再多的正例也证明不了全称命题，它们只能说明"暂时没找到反例"。

### 好的反例长什么样

好的反例满足命题的全部前提，只在结论上失败，并且容易验证。"所有质数都是奇数"的反例是 2：它是质数（满足前提），却不是奇数（结论失败），一眼就能检查。

### 归谬的步骤

1. 假设要证明的结论不成立。
2. 从这个假设出发，按正确的规则一步步推理。
3. 推出矛盾：与已知事实冲突，或者与假设本身冲突。
4. 既然假设导致矛盾，假设就是错的，原结论成立。

## 例子

### 例一：四十个正例也不够

考虑 \(f(n) = n^2 + n + 41\)。n 从 0 取到 39，f(n) 全是质数，很容易让人相信"对所有自然数 n，f(n) 都是质数"。但 n = 40 时：

$$
f(40) = 40^2 + 40 + 41 = 40 \times 41 + 41 = 41 \times 41 = 1681
$$

1681 不是质数。下图是 n = 34 到 41 的值，红色两根是合数：f(41) = 1763 = 41 × 43 也不是质数。

<figure class="chart" data-lecture="LOG-L05" data-id="c2" data-type="echarts"></figure>

### 例二：用归谬证明

命题：如果 \(n^2\) 是偶数，那么 n 是偶数。

假设结论不成立，即 n 是奇数，可以写成 \(n = 2k + 1\)。那么

$$
n^2 = 4k^2 + 4k + 1 = 2(2k^2 + 2k) + 1
$$

是奇数，与"\(n^2\) 是偶数"矛盾。所以假设错误，n 是偶数。这个证明也可以看成第 2 讲的逆否：证明"n 是奇数 ⇒ \(n^2\) 是奇数"。

| 项目 | 反例 | 归谬 |
|---|---|---|
| 用来做什么 | 推翻全称命题 | 证明一个命题 |
| 需要什么 | 一个满足前提、结论不成立的对象 | 从结论的否定出发推出矛盾 |
| 依据 | "不是所有"等于"存在一个不" | 推出矛盾的假设不能成立 |

## 常见误区

- **用正例"证明"全称命题**：例一说明，四十个正例也可能被第四十一个推翻。
- **举的反例不满足前提**：反驳"所有质数都是奇数"时举 9 不算，9 不是质数。
- **归谬没推出真正的矛盾**：推出一个"看起来奇怪"的结论不等于矛盾，必须与已知事实或假设直接冲突。

:::: details 自测题

**第 1 题**　给"对所有 n ≥ 2，\(2^n - 1\) 都是质数"找一个反例。

::: details 答案
n = 4：\(2^4 - 1 = 15 = 3 \times 5\)，不是质数。
:::

**第 2 题**　用归谬证明：如果 \(n^2\) 是奇数，那么 n 是奇数。

::: details 答案
假设 n 是偶数，\(n = 2k\)，则 \(n^2 = 4k^2 = 2(2k^2)\) 是偶数，与 \(n^2\) 是奇数矛盾，所以 n 是奇数。
:::

**第 3 题**　有人说"我试了 100 个数都成立，所以对所有数都成立"。这个推理错在哪里？

::: details 答案
正例只能说明"还没找到反例"，不能代替对所有情况的论证；第 101 个数就可能是反例。
:::
::::

## 小结

- 一个满足前提、结论失败的反例，就足以推翻全称命题；正例再多也证明不了它。
- 归谬先假设结论不成立，推出矛盾，从而证明结论成立。
- 两者都依赖量词的否定："不是所有都满足"等于"存在一个不满足"。
