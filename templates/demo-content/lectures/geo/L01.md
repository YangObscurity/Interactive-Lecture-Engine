# 第1讲 · 坐标与向量

> 节点 `geo_vec` ｜ 亚组: GEO（几何与作图） ｜ 难度 ★ ｜ 预估 20min ｜ 前置: mea_units ｜ 后续: geo_trig、geo_xform

## 要点

用两个数 \((x, y)\) 就能确定平面上的一个点，这就是直角坐标。从一个点指向另一个点的箭头叫[向量](concept:vector)：它有大小也有方向，用分量写成 \((x, y)\)。向量相加就是分量分别相加，画出来就是"首尾相接"。

## 讲解

### 坐标：给每个点一个地址

在纸上画两条互相垂直、交于原点 \(O\) 的数轴，横的叫 \(x\) 轴，竖的叫 \(y\) 轴，并选定单位长度（例如 1 格 = 1 m）。平面上任一点都对应唯一一对数：先读横向走了多少，再读纵向走了多少。[量与单位](../mea/L01.md)那一讲说过，数值离不开单位；坐标也一样，"(3, 4)"要配上"单位 m"才有意义。

两点 \(A(x_1, y_1)\)、\(B(x_2, y_2)\) 之间的距离由勾股定理给出：

$$
|AB| = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}
$$

### 向量：有方向的量

从 \(A\) 走到 \(B\)，记作向量 \(\vec{AB} = (x_2 - x_1,\; y_2 - y_1)\)。它只记录"往哪个方向、走多远"，不在乎从哪里出发：从 (0, 0) 走到 (3, 4)，和从 (10, 10) 走到 (13, 14)，是同一个向量 \((3, 4)\)。向量 \(\vec v = (x, y)\) 的长度（模）是

$$
|\vec v| = \sqrt{x^2 + y^2}
$$

只有大小、没有方向的量叫标量，例如质量、温度、路程。位移、速度、力都是向量。

### 加法与数乘

- **加法**：\((x_1, y_1) + (x_2, y_2) = (x_1 + x_2,\; y_1 + y_2)\)。几何上把第二支箭头的尾接到第一支的头，从起点指向终点的箭头就是和（三角形法则）；把两支箭头从同一点出发画成平行四边形，对角线也是和（平行四边形法则）。
- **数乘**：\(k(x, y) = (kx, ky)\)。\(k > 0\) 方向不变、长度变成 \(k\) 倍；\(k < 0\) 方向反过来。
- **减法**：\(\vec a - \vec b = \vec a + (-1)\vec b\)，几何上是从 \(\vec b\) 的头指向 \(\vec a\) 的头。

## 例子

无人机从起点出发，先向东飞 300 m，再向北飞 400 m，然后向西飞 100 m。取东为 \(x\) 正方向、北为 \(y\) 正方向，单位 m。

1. 三段位移：\((300, 0)\)、\((0, 400)\)、\((-100, 0)\)。
2. 总位移：\((300 + 0 - 100,\; 0 + 400 + 0) = (200, 400)\)。
3. 离起点的直线距离：\(\sqrt{200^2 + 400^2} = \sqrt{200000} \approx 447\) m。
4. 飞过的路程：\(300 + 400 + 100 = 800\) m。

路程 800 m 比直线距离 447 m 长得多。想原路直线返回，需要的位移是 \((-200, -400)\)，正好是总位移的相反向量。

## 常见误区

- **把点的坐标和向量混为一谈。** 点 (3, 4) 是一个位置；向量 (3, 4) 是一次"向右 3、向上 4"的移动，可以从任何地方开始。
- **把长度直接相加。** 长度 3 的向量加长度 4 的向量，和的长度在 1 到 7 之间，只有方向相同时才是 7。
- **坐标的顺序颠倒。** \((x, y)\) 先横后纵；(2, 5) 和 (5, 2) 是不同的点。

:::: details 自测题

**第 1 题**　求点 \(A(1, 2)\) 到 \(B(4, 6)\) 的距离和向量 \(\vec{AB}\)。

::: details 答案
\(\vec{AB} = (3, 4)\)，距离 \(\sqrt{9 + 16} = 5\)。
:::

**第 2 题**　\(\vec a = (2, -1)\)，\(\vec b = (-3, 4)\)，求 \(\vec a + \vec b\) 与 \(2\vec a - \vec b\)。

::: details 答案
\(\vec a + \vec b = (-1, 3)\)；\(2\vec a - \vec b = (4, -2) - (-3, 4) = (7, -6)\)。
:::

**第 3 题**　一个向量长度为 10，横向分量是 6，纵向分量可能是多少？

::: details 答案
\(\sqrt{10^2 - 6^2} = 8\)，所以是 8 或 -8。
:::
::::

## 小结

- 直角坐标用 \((x, y)\) 给每个点一个地址；两点距离用勾股定理。
- 向量有大小有方向，写成分量 \((x, y)\)，长度 \(\sqrt{x^2 + y^2}\)，与起点无关。
- 向量加法是分量相加、首尾相接；数乘改变长度，负数还会反向。
