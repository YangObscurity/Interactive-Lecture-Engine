# 第5讲 · 坐标变换

> 节点 `geo_xform` ｜ 亚组: GEO（几何与作图） ｜ 难度 ★★★ ｜ 预估 30min ｜ 前置: geo_vec、geo_trig ｜ 后续: 无

## 要点

平移、旋转、缩放、翻折是最基本的四种几何变换，用坐标都能写成简单的公式。平移和旋转不改变形状和大小，缩放改变大小但保持相似。几个变换连着做时，**顺序不同，结果一般不同**。

## 讲解

### 四种基本变换

把平面上每个点 \((x, y)\) 按同一规则搬到新位置 \((x', y')\)：

| 变换 | 公式 | 保持不变的 |
|---|---|---|
| 平移 \((a, b)\) | \(x' = x + a,\; y' = y + b\) | 长度、角度、方向 |
| 绕原点旋转 \(\theta\)（逆时针） | \(x' = x\cos\theta - y\sin\theta,\; y' = x\sin\theta + y\cos\theta\) | 长度、角度 |
| 以原点为中心缩放 \(k\) | \(x' = kx,\; y' = ky\) | 角度、形状 |
| 关于 \(x\) 轴翻折 | \(x' = x,\; y' = -y\) | 长度、角度 |

平移就是给每个点加上同一个[向量](concept:vector)。旋转公式可以这样理解：点 \((x, 0)\) 转 \(\theta\) 后到 \((x\cos\theta, x\sin\theta)\)，点 \((0, y)\) 转 \(\theta\) 后到 \((-y\sin\theta, y\cos\theta)\)，一般的点是这两部分之和——这正是上一讲用正弦、余弦拆分量的反过来用。

转 90° 时 \(\cos 90° = 0\)、\(\sin 90° = 1\)，公式化简为 \((x, y) \to (-y, x)\)，很好记。

### 顺序很重要

点 \((2, 1)\) 先向右平移 3 再绕原点转 90°，得到 \((-1, 5)\)；先转 90° 再平移，得到 \((2, 2)\)。旋转是绕原点转的，平移以后点离原点的位置变了，转出来自然不同。做图形软件、写动画时，变换总是按一个固定顺序排好依次施加：

### 绕任意点旋转

要绕点 \(C\) 而不是原点旋转，分三步：先平移 \(-C\) 把 \(C\) 挪到原点，再旋转，最后平移 \(+C\) 挪回去。这种"移过去、做变换、移回来"的套路，缩放和翻折同样适用。

## 例子

绕点 \(C(2, 1)\) 把点 \(P(5, 3)\) 逆时针旋转 90°。

1. 平移 \(-C\)：\(P - C = (3, 2)\)。
2. 绕原点转 90°：\((3, 2) \to (-2, 3)\)。
3. 平移 \(+C\)：\((-2 + 2, 3 + 1) = (0, 4)\)。

检查：\(|CP| = \sqrt{3^2 + 2^2} = \sqrt{13}\)，新点到 \(C\) 的距离 \(\sqrt{(-2)^2 + 3^2} = \sqrt{13}\)，旋转保持了长度。

同样的计算写成程序：

```python
import math

def rotate(p, c, deg):
    t = math.radians(deg)
    x, y = p[0] - c[0], p[1] - c[1]
    return (c[0] + x * math.cos(t) - y * math.sin(t),
            c[1] + x * math.sin(t) + y * math.cos(t))

print([round(v, 6) for v in rotate((5, 3), (2, 1), 90)])   # [0.0, 4.0]
```

再看缩放：把边长为 2 的正方形以原点为中心放大 \(k = 3\) 倍，边长变成 6，面积从 4 变成 36，正是[比例与相似](./L03.md)里说的 \(k^2 = 9\) 倍。

## 常见误区

- **以为变换的先后无所谓。** 平移和旋转交换顺序，结果通常不同；两个平移交换顺序才一定相同。
- **绕任意点旋转时直接套绕原点的公式。** 必须先把旋转中心移到原点。
- **用角度直接代入弧度制的函数。** 程序里的三角函数大多用弧度，记得先换算，如上面的 `math.radians`。

:::: details 自测题

**第 1 题**　把点 \((3, -2)\) 平移 \((-1, 4)\)，再关于 \(x\) 轴翻折，结果是多少？

::: details 答案
平移得 \((2, 2)\)，翻折得 \((2, -2)\)。
:::

**第 2 题**　把点 \((1, 0)\) 绕原点逆时针旋转 60°，坐标是多少？

::: details 答案
\((\cos 60°, \sin 60°) \approx (0.5, 0.866)\)。
:::

**第 3 题**　一个三角形以原点为中心缩放 \(k = 0.5\)，面积变为原来的多少？

::: details 答案
\(0.5^2 = 0.25\)，即四分之一。
:::
::::

## 小结

- 平移、旋转、缩放、翻折都能用坐标公式表示；旋转 90° 记成 \((x, y) \to (-y, x)\)。
- 平移、旋转、翻折保持长度；缩放保持形状，面积乘 \(k^2\)。
- 多个变换要注意顺序；绕任意点变换用"移过去、做变换、移回来"。
