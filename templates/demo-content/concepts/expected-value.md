# 期望值

## 定义

随机量 \(X\) 取值 \(x_i\) 的概率为 \(p_i\) 时，期望值 \(E[X] = \sum x_i p_i\)。它是大量重复试验后平均值稳定靠近的数，不一定是某次真能取到的值。（出处：<span class="cite" data-cite="https://example.com/demo/concepts/expected-value" title="https://example.com/demo/concepts/expected-value">示例出处</span>）

## 例子

一颗均匀骰子点数的期望是 \((1 + 2 + \dots + 6)/6 = 3.5\)；两颗骰子点数之和的期望是 \(3.5 + 3.5 = 7\)，因为和的期望等于期望的和。（出处：<span class="cite" data-cite="https://example.com/demo/concepts/expected-value" title="https://example.com/demo/concepts/expected-value">示例出处</span>）

## 注意

期望相同的两个选择，波动可以差很多；比较风险要同时看方差或标准差。（出处：<span class="cite" data-cite="https://example.com/demo/concepts/expected-value" title="https://example.com/demo/concepts/expected-value">示例出处</span>）
