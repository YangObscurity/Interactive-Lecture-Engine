# Notion 集成接口（通用）

> 本文说明**如何把 Notion 作为只读内容来源接入本引擎**，以及接入时必须守住的
> 内容契约。全文**不含任何私人数据**：所有示例均为占位符，任何字段都不预置
> 具体值 —— 你需要自己填。
>
> **单页体积较大时**（例如一个 Notion 节点包含数万字符）的合并策略见
> [§4 大节点合并](#4-大节点合并策略) 与 [§5 不变量](#5-合并必须守住的不变量)。

---

## 1. 设计立场：Notion 是**只读输入源**

本引擎与 Notion 的关系是**单向**的：

```
Notion  ──只读拉取──▶  本地转换  ──▶  引擎内容源（content-sources/）  ──▶  站点
```

- **只读**：不调用任何写接口（`create_page` / `update_page` / `patch_block` 等）。
  引擎不向 Notion 回写任何东西 —— 不写进度、不改标签、不加标记。
- **可选**：不接 Notion 完全不影响引擎使用。你可以手写 Markdown，
  也可以用任何其它工具生成，只要满足 [内容源契约](./CONTENT_SOURCE.md)。
- **不预置内容**：引擎不附带任何 Notion 页面 ID、数据库 ID、令牌或节点标题。
  这些**全部由你自己通过环境变量提供**（见 §2）。

> 为什么坚持只读：写权限会把"内容展示工具"变成"内容管理系统"，
> 责任边界立刻变得模糊（谁改的？冲突怎么合？）。保持只读，
> 引擎的职责就只有一件：把已有内容渲染好。

---

## 2. 凭据接入（全部走环境变量，**零硬编码**）

引擎的配置层（`scripts/config.py`）统一管理所有凭据，代码里**不存在任何默认值**：

| 变量 | 用途 | 必填 |
|---|---|---|
| `NOTION_TOKEN` | 集成令牌（只读权限即可） | 接 Notion 时必填 |
| `NOTION_API_VERSION` | REST API 版本，默认 `2022-06-28` | 否 |
| `NOTION_DB_ID` | 知识库数据库 ID（若用数据库作为来源） | 视用法 |

取值优先级：**命令行参数 > 环境变量 > `.env` 文件 > 代码默认值**。

```bash
# 最小接入
cp .env.example .env      # 模板里全是占位符
# 编辑 .env，填入你自己的 NOTION_TOKEN
```

安全约定（**由代码强制，不是靠自觉**）：

- `.env` 已被 `.gitignore` 排除；仓库只保留**只有占位符**的 `.env.example`。
- `config.describe()` 对密钥类字段**自动脱敏**，只回显"已设置（长度 N）"，
  防止调试打印变成二次泄露渠道。
- 缺配置时抛 `ConfigError` 并打印**可执行的修复指引**，而不是拿 `None` 去拼请求头、
  得到一个语焉不详的 401。

> ⚠️ **令牌一旦提交过就必须视为已泄露** —— 从代码里删掉不够，
> 必须去 Notion 后台**吊销并重建**。

### 集成需要显式授权页面

Notion 集成的可见范围**仅限被显式授权的页面/数据库**。若拉取时返回 404，
通常不是令牌错，而是**该页面没有把集成加为连接**：在页面右上角
`···` → `Connections` → 添加你的集成。

## 3. 从 Notion 节点到讲义

一个 Notion 页面转成一讲，需要满足两件事：**结构映射**与**锚点保留**。

### 3.1 结构映射

| Notion | 讲义 |
|---|---|
| 页面 title | frontmatter `title`（**必须英文双引号包裹**） |
| 页面 ordering / 自定义属性 | frontmatter `order` |
| `##` / `###` 标题块 | 同名 Markdown 标题 |
| 段落 / 列表 / 引用 | 对应 Markdown |
| 代码块 | 围栏 + **规范语言标签**（见 §5.4） |
| 图片 / 图表 | **不直接内联** → 转成 `.chart` 占位锚点（见 §5.1） |

### 3.2 必须保留的溯源信息

frontmatter 的 `description` 里保留节点标识，用于回溯：

```yaml
---
title: "第1讲 · 课程主题"
order: 1
description: "节点 `your_notion_node_id` ｜ 难度 ★★ ｜ 预估 90min"
outline: deep
---
```

> 节点标识用**行内代码**书写，避免被 Vue 模板编译器当成标签。
> 具体的 `your_notion_node_id` 由你填 —— 引擎不预置任何值。

## 4. 大节点合并策略

当单个 Notion 节点很大（数万字符）而目标讲义已有内容时，**不能整篇覆盖**。

**核心风险**：站点侧讲义里含有**图表锚点**（`<figure class="chart" …>`），
而 Notion 导出内容通常**不含**这些锚点。整篇覆盖会把所有图表锚点抹掉 ——
图表随之全部消失，且**构建不会报错**（只是页面上图没了），极难发现。

因此必须**按节合并**：

```
[提取] 扫描目标讲义，记录每个 figure 锚点行及其所属的 ## 小节
   ↓
[合并] 用 Notion 内容按 ## 标题匹配替换正文段落
        —— 只替换散文，不碰 frontmatter、不碰 figure 锚点行
   ↓
[回注] 把记录的锚点行按原小节插回
        （位置：该节论述之后、对应图注之前）
   ↓
[对账] 正文里的 data-id 集合 与 sidecar JSON 的 key 集合 必须相等
   ↓
[验证] python scripts/check_figs2.py    # 期望「不一致数: 0」
```

**禁止**：

- ❌ 用一次导出**整篇覆盖**已有讲义；
- ❌ 合并后**手工**补 figure 锚点（极易漏、易重复）—— 必须靠脚本回注；
- ❌ 把 Notion 的速记草稿**原样**搬进来（需按讲义文风重写）。

**建议**：把"提取—合并—回注—对账"四步写成脚本固定下来，避免每次靠记忆操作。

## 5. 合并必须守住的不变量

### 5.1 figure 锚点守恒 ★

```html
<figure class="chart" data-lecture="<课程组>-<讲次>" data-id="c1" data-type="echarts"></figure>
```

1. **一个锚点都不能丢** —— 丢了对应图表直接消失。
2. `data-lecture` 必须与文件名（组 + 讲次）一致；`data-id` 在讲内唯一，建议自 `c1` 连续。
3. `data-id` 集合必须与 `public/charts/<ID>-<讲次>.json` 的 key 集合**严格相等**。
4. `data-type` 与 JSON 里的 `type` 一致。
5. 锚点行**前后各留一个空行**（连续空行会被压回单个）。

校验：`python scripts/check_figs2.py`（期望 `不一致数: 0`）。
该脚本**内置真空防护**：扫不到讲义时会非零退出，而不是报"通过"。

### 5.2 frontmatter

- `title` 必须**英文双引号**包裹（含中文冒号时不加引号会导致 YAML 解析失败）。
- `order` 决定讲次排序（引擎按**数值**排，不是字符串）。

### 5.3 尖括号与模板安全

Notion 内容常含 `<stdio.h>` 这类文本。散文中 `<` 紧跟 ASCII 字母/下划线时
必须转义为 `&lt;`，否则 Vue 会报 *Element is missing end tag*。
完整规则见 [`AGENTS.md` §1](../../AGENTS.md)。

### 5.4 代码围栏语言标签

**严禁**带空格的 `plain text`。使用规范标签：`bash` / `c` / `python` / `json` /
`text` 等（VitePress 用 Shiki 高亮，标签错误会退化为无色）。

## 6. 长页面的阅读体验

- 右侧大纲（`outline: deep`）已能导航多级标题，**长文不需要拆页**。
- 极端情况下（单讲数百 KB 或图表超过十余张）再考虑拆成 `...-a` / `...-b`，
  但**拆页会打断「上一讲 / 下一讲」的连续性**（引擎按 `L*.md` 文件名排序），
  故拆页是下策 —— 优先保持单页。

---

## 7. 诚实声明

- 本文是**接口约定**，不承诺任何具体 Notion 数据形态：不同工作区的属性名、
  块类型、导出格式都可能不同，你需要按实际情况调整映射。
- 引擎**不包含**任何 Notion 抽取脚本的实现，也不预置页面 ID / 数据库 ID /
  节点标题 —— 这些属使用者的私人数据。
- 若你在自己的流程里实现了抽取脚本，建议**不要把它放进本引擎仓库**
  （它会带上你的页面 ID 与工作区结构），而是放在你的私有工具目录里。
